# Desarrollo de Videojuego

## Descripción
Este proyecto consiste en una página web estática desarrollada íntegramente en HTML. El objetivo es la información sobre el desarrollo de videojuegos, integrando elementos multimedia y una interfaz de usuario sin lenguajes de programación externos como javascript. 

## La página incluye:
- Encabezado.
- Un sistema de navegación interactivo para el usuarios.
- Formulario de consultas organizados mediante tablas y fieldsets.
- Integración de contenido multimedia (imágenes y videos).
- Tabla de herramienta basica que debe saber un desarrollador de videojuegos indie

## Contenido
-Página principal
-Imágenes
-Video
-Formulario
